# Tensora Cloud (Lab)

Next.js app based on GradientRL Lab, rebranded for Tensora.

## Dev

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) → Overview.

## Routes

- `/lab/dashboard/overview` — Overview
- `/lab/dashboard/on-demand-gpus` — Cloud
- `/lab/network` — Network providers
- `/lab/activity` — Activity feed
- `/lab/inference` — Inference (demo unlocked)

Demo mode is on by default (`NEXT_PUBLIC_DEMO_MODE=true`).
