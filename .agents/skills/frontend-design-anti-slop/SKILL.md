# Frontend design — anti-slop

## Before coding
1. State the **one job** of the first viewport in one sentence.
2. Name the **one focal element** (not five equal panels).
3. Confirm you will reuse the project's existing tokens/components unless the user asked for a full rebrand.

## Hard bans (AI-slop cluster)
- Purple-on-white / purple→indigo gradient themes
- Warm cream `#F4F1EA` + terracotta + high-contrast serif “editorial” default
- Broadsheet: hairline rules, zero radius, dense newspaper columns
- Default stacks only: Inter, Roboto, Arial, system — when the project already has brand fonts
- Glow everywhere, multi-layer shadows, rounded-full pill clusters, emoji decoration
- Card grids in heroes; floating badge/sticker overlays on media
- “Glassmorphism soup” and neon cyberpunk terminals unless that is the brand

## Prefer
- Clear hierarchy: one display size, one supporting line, one CTA group
- Real product/place imagery or meaningful data UI — not abstract blobs alone
- Spacing rhythm (8/12/16) and intentional empty space
- Motion: 2–3 purposeful transitions, not constant shimmer
- Existing design system first; invent new chrome last

## Critique gate
If redesigning an existing page the user likes, propose the composition in ≤5 bullets and wait for approval before ripping the layout — unless they explicitly said “just do it.”
